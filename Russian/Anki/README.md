# Russian Anki Decks

A collection of [Anki](https://apps.ankiweb.net/) decks for learning Russian, from absolute beginner to advanced. All decks are compatible with **Anki Desktop**, **AnkiDroid** (Android), and **AnkiMobile** (iOS).

---

## What is Anki?

[Anki](https://apps.ankiweb.net/) is a **spaced repetition** flashcard program. It shows you cards right before you forget them, making vocabulary and phrase memorization far more efficient than traditional study.

- **AnkiDroid** — official Android app: [F-Droid](https://f-droid.org/packages/com.ichi2.anki/) or [Google Play](https://play.google.com/store/apps/details?id=com.ichi2.anki).
- **AnkiMobile** — iOS app: [App Store](https://apps.apple.com/app/ankimobile-flashcards/id373493387).
- Decks (`.apkg`) can be imported directly into any of these apps.

## 📚 Deck Details

### A0.apkg — *Work in Progress* 🚧

Basic phrases extracted from YouTube videos, designed as starter material for absolute beginners.

- **Current content:** 4 phrases (one per processed video).
- **Status:** Actively being expanded. More phrases will be added with each new batch of videos.
- **Goal:** Cover the most elementary spoken Russian structures before moving on to A1.

> ⚠️ **This deck will be updated periodically.** Re-download it when a new release is published.

### A1.apkg

A1-level deck with **200 useful sentences** and **800 high-frequency words**, all with **real audio** (Microsoft Edge TTS neural voices).

- **Sentences:** 200 everyday sentences (greetings, asking for help, restaurant, directions, emergencies, etc.).
- **Words:** 800 terms ordered roughly by frequency of use, from `и` (and) to `солёный` (salty).
- **Audio:** Every card includes an MP3 file generated with the `ru-RU-SvetlanaNeural` voice.
- **Format:** Russian → English (recognition). Gender variants share the same card.

### Basic.apkg

Basic words and phrases from the [StringManolo/Languages](https://github.com/StringManolo/Languages) repository, Russian folder.

- **Content:** Fundamental vocabulary and expressions.
- **Original source:** [github.com/StringManolo/Languages](https://github.com/StringManolo/Languages)

### Core5000.apkg — *Third-Party Deck*

The 5,000 most frequent Russian words, based on corpus analysis.

- **Content:** ~5,000 vocabulary cards with audio, example sentences, stress marks, and English translations.
- **Original author:** See [Credits](#-credits--attributions).

### LingoLlama.apkg — *Third-Party Deck*

Russian sentences for beginners with audio, designed for contextual learning.

- **Content:** 253 sentence cards with audio.
- **Original author:** See [Credits](#-credits--attributions).

### Numbers.apkg

All Russian numbers from **0 to 1,000,000,000**.

- **Includes:** 0–20, 30, 40, 50, 60, 70, 80, 90, 100, 200…900, 1,000, 2,000…10,000, 100,000, 1,000,000, 1,000,000,000.
- **Excludes (predictable):** 21–29, 31–39, 41–49… (all combinations of tens + units), and their equivalents in hundreds and thousands.
- **Purpose:** Learn the logic of Russian number formation without memorizing predictable combinations.

## 🚀 How to Import a Deck

1. Download the `.apkg` file from the [Downloads](#-downloads) table.
2. Open **Anki** (Desktop, AnkiDroid, or AnkiMobile).
3. Go to **File → Import** (or the **+** button on mobile).
4. Select the downloaded `.apkg` file.
5. Done! The cards will appear in your collection.

> **Tip:** In AnkiDroid, you can import directly from your phone's file browser or by sharing the `.apkg` file to the app.
